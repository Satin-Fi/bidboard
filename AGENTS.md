## 1. Master Design System (`DESIGN.md`)
Always read and respect the guidelines in [DESIGN.md](./DESIGN.md):
- **Theme**: Precision Dark Mode (`#0b0c10` obsidian canvas, `#13151c` surface, `#f97316` coral accent).
- **Typography**: Display headlines + crisp neutral body (`Inter`) + tabular data (`JetBrains Mono`).
- **Icons**: Vector SVG icons ([Lucide](https://lucide.dev)) only. Never use system emojis in UI elements.
